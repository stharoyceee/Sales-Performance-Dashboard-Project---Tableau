# 📊 Executive Sales & Profitability Dashboard (Tableau)

An interactive Tableau dashboard designed to track year-over-year (YoY) sales, profit, and order volume across product categories and geographic regions.

## ✨ Key Features
* **YoY KPI Sparklines:** Tracks Total Sales, Profit, and Quantity against the prior year, automatically highlighting peak (cyan) and trough (orange) months.
* **Weekly Performance Trends:** Step-line charts measuring weekly sales and profit against dynamic annual averages.
* **Subcategory Breakdown:** Combines a YoY sales bullet chart with a diverging profit/loss bar chart to quickly spot top performers and loss-making items.
* **Interactive UX:** Includes cross-filtering highlight actions (click any subcategory to isolate its trends) and a collapsible filter drawer (Year, Category, Sub-Category, Region).

## 🚀 How to View
1. Download `Sales_Dashboard.twbx` from this repository.
2. Open it using **Tableau Desktop** or the free **Tableau Public** app.
